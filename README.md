# Solar Flow Hero

An animated solar-energy explainer built with React, Vite, SVG, and CSS animation. The visual communicates the flow from **sunlight → solar panels → inverter → home → bill savings**.

## What is included

- `src/SolarHero.jsx` — React implementation of the animated hero
- `src/hero.css` — animation and presentation styles
- `solar-flow-elementor.html` — standalone HTML/SVG version for an Elementor HTML widget
- `index.html` — Vite preview entry point

## Animation

The hero uses CSS-driven motion for the entrance sequence and ambient effects such as flowing energy lines, sun glow, inverter activity, and savings movement. A reduced-motion mode is included for accessibility.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Elementor version

Open `solar-flow-elementor.html` and paste its contents into an Elementor HTML widget when a self-contained version is needed.

## Project status

This repository is kept intentionally focused on the source implementation and deployable HTML. Generated GIFs, frame captures, and local capture helpers are not tracked.
